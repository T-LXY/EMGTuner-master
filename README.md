To run the pipeline:
    1. Install dependencies
    2. Open the desired model version (version is detailed in file name).
    3. Run the ipynb file.

Version descriptions:
    v1, v2, v3: LSTM model. v2 is best performing and v3 is the same as v2 but dropping the imbalanced label 7.
    v4, v5: CNN-LSTM model. v5 is best performing.
